# Support

Litebox is maintained as a community open-source project.

## Where to ask

- Use GitHub Discussions for setup questions, operating advice, and ideas that
  are not yet actionable issues.
- Use the bug report form for a reproducible defect in Litebox.
- Use the feature request form for a concrete product proposal.
- Use a private security advisory for vulnerabilities; see
  [SECURITY.md](SECURITY.md).

Before asking, check the [README](README.md), the documentation under `docs/`,
closed issues, and the output of `mailbox doctor --deep`.

Community support is best-effort and has no response-time guarantee. Include the
Litebox version, deployment method, operating system, redacted configuration,
and relevant logs. Never post API keys, webhook secrets, cookies, email bodies,
attachment content, database files, or unredacted addresses.

Questions about Resend accounts, DNS verification, quotas, or delivery policy
belong with Resend support. Questions about reverse proxies, container runtimes,
or hosting providers may require support from those projects.
