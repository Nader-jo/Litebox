# Contributors

Litebox is possible because people contribute code, testing, documentation,
design feedback, issue reports, security review, and patient support.

## Project contributors

- [Nader Jemaa (@Nader-jo)](https://github.com/Nader-jo) — creator and lead
  maintainer.

Dependabot and GitHub Actions also provide automated dependency and repository
hygiene updates.

## Join the list

Every constructive contribution is welcome, including changes that do not add
code. Contributor names are added from merged pull requests; contributors may
request a preferred name or opt out of recognition.

Start with [CONTRIBUTING.md](CONTRIBUTING.md), choose an issue labeled for
contributors, or propose a small documentation or test improvement. All
participation follows the [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for making self-hosted email simpler, safer, and more humane.
